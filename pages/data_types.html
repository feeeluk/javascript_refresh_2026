Data Types

Variables can be of different types (data types).

See console output

First, we explore the different data types in JavaScript, including STRING, NUMBER, and BOOLEAN, and what happens when we convert between them. See the code for the details.

Then, we ask the user for their age (prompt removed and input field added), add 1 to it, and then log the result to the console. Without converting the input to a NUMBER, the + operator would concatenate the STRING instead of performing addition (which we see as the first value in the console). We use Number() to convert the input type of STRING to a NUMBER, and thus allowing us to correctly add 1 to the user's age (which we see as the second value in the console).
