Destructuring

Description

Extract values from variables, arrays or objects, then assign them to other variables.

[] = to perform array destructuring
{} = to perform object restructuring

How is it used / why is it important?

Destructuring — lets a developer pull specific fields out of API responses (e.g., const { title, id } = data) so they can work directly with the values they need instead of repeatedly accessing deep object paths.
