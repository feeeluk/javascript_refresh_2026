Constructors

Description

A special method for defining the properties and methods of an object. An object is an instance of a class, and each instance is created via a constructor. Old style JavaScript code allowed for constructors to be used outside of classes, but that is old-hat! DO NOT DO IT! It makes much more sense (and is standard practice in most other languages) to use constructors within classes.
