This

Description

A keyword. It is a reference to the object where 'this' is used (its use depends on context).
e.g. if you are working inside Object1 'this' refers to the properties of Object1.

*Note: 'this' doesn't just work with Objects, it will return whatever the current context is, whether that is an object or a window, or anything else. It is mentioned here specifically for use with object.
**Note: 'this' doesn't work with Arrow Functions.
