Classes

OOP - A class is a blueprint for creating objects — it defines the shape and behaviour that many similar things can share. In JavaScript, a class bundles data and functions together so you can create multiple objects with the same structure without rewriting the logic each time.

A class is a template — it describes what an object should look like and what it can do, but it isn’t a real thing by itself. An object is the actual instance created from that template, holding real data and its own state while using the behaviour defined by the class.
