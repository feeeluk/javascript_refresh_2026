How is it used / why is it important?

Event listeners allow JavaScript to react to user actions in real time, which is what makes web pages feel interactive and alive. They also keep code modular by letting you attach multiple independent behaviours to the same element without overwriting anything, unlike a single onclick handler.

There are two approaches to handling 'events'. The first is direct, the second is using an 'event listener'.
The 'direct approach' (see example below) is old hat, and can only hold one function — assigning another one replaces it. However, 'event listeners' let you attach multiple independent handlers.

Direct

const box = document.getElementById("myBox");
box.onclick = () => {
console.log("Box was clicked");
};

Event Listener

const box = document.getElementById("myBox");
box.addEventListener("click", () => {
console.log("Box was clicked");
});
