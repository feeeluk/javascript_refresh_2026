JSON (JavaScript Object Notation)
Data-interchange format.
Used for exchanging data between a server and a web application.
JSON files are made up of objects, arrays, or objects that contain arrays, or arrays that contain objects.

JSON.stringify() = converts a JS object into a JSON string.
JSON.parse() = converts a JSON string into a JS object.

How is it used / why is it important?

JSON acts as the universal format for sending and receiving data between the browser and servers, requiring the developer to convert between JSON strings and JavaScript objects.
