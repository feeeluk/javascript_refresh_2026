Description

A NodeList is a static collection of HTML elements (by "ID", "class", "element").
It can be vreated by using queryySelectorAll().
It is similar to an array, but with no map() or filter() or reduce().
NodeList is not dynamic, so it won't update to automatically relect any changes made.

querySelectorAll (which creates the NodeList) is different to queryySelector because it returns ALL matching elements, not just the first one.

How is it used / why is it important?

NodeList = represents the result of selecting multiple DOM elements, allowing the developer to loop over groups of elements (e.g., all buttons or all list items).
