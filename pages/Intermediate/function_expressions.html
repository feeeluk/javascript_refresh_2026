Description

Function Expressions are a way to define a function as a value or a variable.
They are not declared and then called (as with a 'normal' function), they are literally written in situ

Function Declaration (a normal function) = Defines a reusable block of code that performs a specific task.

Their very existence is quite unique to JavaScript, actually. Traditional programming languages typically use function declarations exclusively.
The key difference between the two is that a function declaration is like saying:

“Here is a tool. I might use it multiple times.”

Whereas a function expression is like saying:

“I need a tool right now, in this exact position, because I’m handing it to something.”

How is it used / why is it important?

Why might you need "a tool right now, in this exact position"?
Here is a great example using Promises. While Promises are an advanced topic, the point applies accross the board.

Function declaration

function executor(resolve, reject) {
resolve("done");
}

new Promise(executor);

Function expression

new Promise(function(resolve, reject) {
resolve("done");
});

Arrow function

new Promise((resolve, reject) => {
resolve("done");
});
