Description

Splice lets you remove, replace, or insert items in an array.

Mutates the original array. Adds, removes, or replaces items.

array.splice(index, howManyItemsToDelete, addItem1AtIndex, addItem2AtIndex, etc...)

  • Remove items
  • Insert items
  • Replace items
  • Remove everything from a point onward

How is it used / why is it important?

Splice() is used to change an array in place — by removing, inserting, or replacing items. It’s important because it’s the only built‑in array method that can surgically modify the original array at any position.
