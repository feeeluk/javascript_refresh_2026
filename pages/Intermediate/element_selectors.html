Element Selectors
Back

Description

Methods used to target and manipulate HTML elements. They allow you to select one of multiple HTML elements from the DOM.

  • document.getElementById() // Element or Null
  • document.getElementsClassName() // HTML Collection
  • document.getElementByTagName() // HTML Collection
  • document.querySelector() // Element of Null
  • document.querySelectorAll() // Nodelist

How is it used / why is it important?

Element Selectors allow a developer to grab specific elements from the page (e.g., buttons, inputs, sections) so they can update content, attach events, or manipulate the UI.
This is a CORE part of JavaScript as it is one of the ways that JavaScript interacts with HTML.
