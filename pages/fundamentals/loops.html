Description

A loop repeats blocks of code.
There are different types:

  • For loops
  • Do loops
  • Do While loops

How is it used / why is it important?

A developer uses a for loop when they need precise control over the index (e.g., skipping items, jumping ahead, looping backwards, or modifying array elements in place), which makes it ideal for tasks like updating a list of objects, stepping through API results, or running something a fixed number of times.

See console output.

For loops

Repeat some code FOR a set amount of times.
For loops work really well with arrays, and objects.

While loops

Repeat some code WHILE a condition is true.
Potentially infinite.
