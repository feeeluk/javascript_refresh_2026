Variables

Description

A container that stores a value. Behaves as if it was the value that it contains. A variable's value can be changed after it is assigned (mutable).

Declared:

let variableOne;

Assigned:

variableOne = 1;

Assigned and Declared at the same time:

let variableOne = 1;

How is it used / why is it important?

A fundamental building block of programing. Not just in JavaScript, but ALL programing languages.
