Truthy / Falsy
Back

Description

In JavaScript, any value used inside an if statement must be interpreted as either true or false, and truthy/falsy is simply the rule JavaScript uses to decide which way to go.

There are only 7 values that JavaScript treats as false:

  • false (boolean)
  • 0 (number)
  • -0 (number)
  • "" (empty string)
  • null
  • undefined
  • NaN
If a value is not one of these, it is truthy.

How is it used / why is it important?

Truthy / Falsy is basically shorthand.

if (username !== "")

is the same as

if (username)

These are some common examples where they are used:

  • Checking if a string has content

    if (username) { ... }

  • Checking if an array has items

    if (items.length) { ... }

  • Checking if an API returned an error

    if (data.error) { ... }
