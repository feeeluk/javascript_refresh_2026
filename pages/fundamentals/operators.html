Description

Arithmetic Operators

  • + (addition)
  • - (subtraction)
  • * (muliplication)
  • / (division)
  • % (modulus)
  • ** (exponent / power)

Comparison Operators

  • == (equal)
  • != (not equal)
  • === (strict equal)
  • !== (strict not equal)
  • > (greater than)
  • < (less than)
  • >= (greater than or equal)
  • <= (less than or equal)

Logical Operators

  • && (AND - both must be true)
  • || (OR - either can be true)
  • ! (NOT - negates a value - flips a positive to a negative, vice-versa)

Assignment Operators

  • = (assign a value)
  • += (add and assign)
  • -= (subract and assign)
  • *= (multipy and assign)
  • /+ (divide and assign)
  • %= (modulus and assign)

String Operators

  • + (concatenate)

Unary Operators

  • ++ (increment)
  • -- (decrement)

How is it used / why is it important?

  • Arithmetic Operators
    Used for working with numbers.
  • Comparison Operators
    Used for comparing values (regardless of type). Some of these operators can only work with numbers e.g. 'greater than'. They are great for use with if statements.

    See the strict equality section for more details on this operator.
  • Logical Operators
    Used for working with boolean values, e.g. create an if statement with TWO or more conditions (that can be mutually exlusive or NOT mutally exclusive).

    Example 1 - if both values match then do 'xyz'
    if(value = something && anotherValue = somethingElse){
    }

    Example 2 - if one or the other values match then do 'abc'
    if(value = something || anotherValue = somethingElse){
    }

  • Assignment Operators
    Used for asigning a value to a variable or a constant.

    Example 1 - simple assignment
    let total = 5;

    Example 2 - take the current value and add something to it
    total += 3; // adds 3 to 'total', so that it is now 8

  • String Operators
    Used for string concatenation (adding different strings together).

    Example 1 - using string concatenation
    "this" + " " + "is" + " " + "concatenation"

  • Unary Operators
    Really simple incremental / decremental tools ideal for use as a counter (e.g. loops).
