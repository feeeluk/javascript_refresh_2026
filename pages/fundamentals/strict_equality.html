Description

Strict Equality / Scrict Inequality (3 = signs) is different to equality / inequality (2 = signs) in that it checks both the VALUE and the DATA TYPE!

How is it used / why is it important?

General equality (==) is not very specific as JavaScript doesn't enforce variable data types. Therefore using a standard equality check could easily evaluate a string as the same value as a number, etc.. So using the strict equality operator can be help mitigate these sort of errors, e.g. user input is often capured as a string, so this operator could be used to avoid coding errors.

Example 1 - a variable containing a string
const PI = 3.14; // constant contains a number
if(PI = "3.14"){} // evaluates as TRUE even though the value was a string!
