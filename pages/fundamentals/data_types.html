Description

Variables can be of different data types.

How is it used / why is it important?

This is a fundamental part of programing. Not just in JavaScript, but ALL programing languages. Data can come in all different types, so being able to recognise and work with these different data types is essential.

First, we explore the different data types in JavaScript, including STRING, NUMBER, and BOOLEAN, and what happens when we convert between them. See the code for the details.

Then, we ask the user for their age, add 1 to it, and then log the result to the console. Without converting the input to a NUMBER, the + operator would concatenate the STRING instead of performing addition (which we see as the first value in the console). We use Number() to convert the input type of STRING to a NUMBER, and thus allowing us to correctly add 1 to the user's age (which we see as the second value in the console).
