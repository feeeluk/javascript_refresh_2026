Array Methods



2D Arrays

A 2D array is an array containing two arrays (an array for each dimension).



3D Arrays

A 3D array is an array containing three arrays (an array for each dimension).



Jagged Arrays

A jagged array is an array of arrays where each sub-array can have a different length.
