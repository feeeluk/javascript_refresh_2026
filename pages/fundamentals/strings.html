Description

A string is a type of data. A single string (singular) is a single character (letter, symbol, or number), they can be individual characters or groups (groups are known as strings - plural).

How is it used / why is it important?

Strings are a fundamental part of programing. Not just in JavaScript, but ALL programing languages. Strings have lots of dedicated functions - see the 'resources' section for more.
