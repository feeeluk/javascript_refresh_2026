Description

Whereabouts in code a variable is recognised and accessible.

  • Local / Function scope = a variable exists only inside the function where it was declared, and nowhere outside it.
  • Block scope = a variable declared with let or const only exists inside the { } block where it was created.
  • Global scope = a variable is available everywhere in your program, because it was declared outside any function or block.

How is it used / why is it important?

Understanding variable scope is a fundamental part of programming as understanding where you are storing variables is key to accessing and using them correctly.
