Functions

Description

A function (also known as a 'Function Declaration') is a section of reusable code, i.e. declare some code once then use it whenever you want by 'calling' / 'invoking' / 'executing' it to run the code.

  • Functions can take arguments (known as parameters when passed into the function).
  • To create a function, use the keyword 'function' (declares the function).
  • Use camelCase naming convention.
Example - A simple function that accepts arguments:

function simpleFunction(argument1, argument2)
{
console.log(argument1);
console.log(argument2);
}

Example - Calling a function and passing it some parameters:

simpleFunction("one", "two");

How is it used / why is it important?

They are a fundamental and essential building block of programing. Not just in JavaScript, but ALL programing languages.
They save an enourmous amount of time (remember the DRY principle of DO NOT REPEAT YOURSELF). Working with variables/constants and functions is 99% of programming.
