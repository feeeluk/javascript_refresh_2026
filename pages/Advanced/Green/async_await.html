Async / Await

Description

Synchronous = Executed line by line consecutively in a sequential manner. Code that waits for an operation to complete.
Asynchronous = Allows multiple operations to be performed concurrently without waiting. Doesn't block the execution flow and allows the program to continue.

How is it used / why is it important?

Async / Await — allows asynchronous code to be written in a readable, top‑to‑bottom style (e.g., const data = await fetch(url)), making API workflows feel synchronous.
Ideal for use with I/O operations, network requests, fetching data. Handled with: Callbacks, Promises, Async/Await.
