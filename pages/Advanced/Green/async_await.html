Description

Async = makes a function return a promise.
Await = make an async function WAIT for a promise to complete.

Using Async without await is common practice!!!!!!!!!!!
You DO NOT HAVE TO USE AWAIT!
Using AWAIT allows you to write asynhronous code in an synchronous manner.
Everything after Await is placed in an event queue.
AWAIT literally pauses the flow of the program until the promise has returned (literal meaning. It 'awaits' the return of the promise before continuing).

Async promises don't have resolve or reject parameters.








How is it used / why is it important?

Async / Await — allows asynchronous code to be written in a readable, top‑to‑bottom style (e.g., const data = await fetch(url)), making API workflows feel synchronous.
Ideal for use with I/O operations, network requests, fetching data. Handled with: Callbacks, Promises, Async/Await.
