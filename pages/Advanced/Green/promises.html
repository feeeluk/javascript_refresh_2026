Description

Promises provide a structured way to handle operations that complete later (like API calls), ensuring the code can react when the data finally arrives.

A promise does not have to live inside an async function, however if you want that promise to resolve before doing something else, then it needs an 'await' when it is called.

A 'promise' is an object. A new instance of that object can be instantiated using the 'Promise' constructor.
Promises contain state (pending, fulfilled, rejected), and a result (the value or error).

new Promise((resolve, reject) => {})

This hands an arrow function expression to the Promise constructor.
Then JavaScript does this:

  1. It creates a new Promise object.
  2. It immediately calls your function.
  3. It passes two arguments into your function:
    • a function called resolve (parameter)
    • a function called reject (parameter)
