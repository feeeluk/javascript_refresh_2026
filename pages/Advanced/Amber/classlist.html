Description

Classlist is an element property in Javascript (meaning in applies to every element). It is used to interact with an element's list of classes.
Thus allowing reusable classes for many elements across a webpage.

  • add()
  • remove()
  • toggle()
  • replace()
  • contains()

How is it used / why is it important?

ClassList provides a clean way to add, remove, or toggle CSS classes on elements, which is essential for showing/hiding UI components or changing styles dynamically.

*Note - CSS classes are HUGELY different to JavaScript classes!
