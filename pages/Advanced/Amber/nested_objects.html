Nested objects

Description

By putting Objects inside other Objects we are able to represent more complex data structures. A child Object is enclosed by a parent Object
e.g. Person{Addres{}, contactInfo{}}

How is it used / why is it important?

Nested objects appear in complex API responses (e.g., user.address.city), requiring the developer to safely access and update deeply nested data.
