Description

Closures allow functions to “remember” variables from their creation context, enabling patterns like private state, event handler factories, and custom utility functions.

At first the concept of Closures seems very abstract and complicated.
Closures ARE NOT COMPLICATED AT ALL!

A Closure is simply a function that retains access to the specific scope in which it was created, even after that scope has finished executing.

That seems very wordy, but it is essentially very simple. Imagine nested functions. All child functions have access to the resurces created in the parent function. Those resources expire when the function expires, but if you return the child function as a result of running the parent function and store it in memory, then the parent's resources are still alive.
