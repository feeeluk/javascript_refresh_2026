Description

Error Handling ensures the program can gracefully respond when something fails (like a network error or invalid JSON) instead of crashing.
There are several different types of error, but unless they are handled correctly they will interrupt the flow of the program, and the program may not even complete.

When we say 'handle' we mean use 'try()', 'catch()', and 'finally()' blocks.

  • try() = encloses code that might potentially cause an error
  • catch() = Catch and handle any thrown errors from try()
  • finally() = optional, but always executes. Used mostly for clean up, e.g. closes files, close connections, release resources.

How is it used / why is it important?

An error is an object that is created to represent a problem that occurs.
They often occur with user input or establishing a connection.
