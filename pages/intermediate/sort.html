Description

A method to sort elements of an array in place.
Sorts elements as strings in lexicographic order, not alphabetic. Lexicographic = (alphabet + numbers + symbols) as strings.

How is it used / why is it important?

Groups of data (e.g. arrays) contains lots of different elements. These elements might not necessarily be in a desired order. Using this method on an array fixes that by arranging the elements inside of it to the order specified.
