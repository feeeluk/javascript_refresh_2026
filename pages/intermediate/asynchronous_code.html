Description

Synchronous = Executed line by line consecutively in a sequential manner. Code that waits for an operation to complete.
Asynchronous = Allows multiple operations to be performed concurrently without waiting. Doesn't block the execution flow and allows the program to continue.

Different ways of working can be achieved by mixing these concepts.. For example, you could set one function to run asynchronously, but then be followed by synchronous code that will not execute until the asynchronous function has finished.

In the examples used, we create an async function that calls functions that already return a promise.
