Constants

Description

A container that stores a value. Behaves as if it was the value that it contains.
Constants cannot not change value once assigned (immutable).

const constantOne = 1;
const constantTwo = "two";
const constantThree = [1,2,3];

Declared:

const constantFour;

Assigned:

constantFour = 1;

Assigned and Declared at the same time:

const constantFour = 1;

*Note - even if an array or object is assigned to a constant, the values inside that array or objects can change, but NOT the assignment of the constant!

How is it used / why is it important?

A fundamental building block of programing. Not just in JavaScript, but ALL programing languages.
