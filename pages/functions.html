Functions

Description

A function (also known as a 'Function Declaration') is a section of reusable code, i.e. declare some code once then use it whenever you want by 'calling' / 'invoking' / 'executing' it to run the code.
Functions can take arguments (known as parameters when passed into the function).

Example - A simple function that accepts arguments:

simpleFunction(argument1, argument2)
{
console.log(argument1);
console.log(argument2);
}

Example - Calling a function and passing it some parameters:

simpleFunction("one", "two");
