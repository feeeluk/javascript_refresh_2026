Async

Synchronous = Executrd line by line consecutively in a sequential manner. Code that waits for am operation to complete.

Asynchronous = Allows multiple operations to be performed concurrently without waiting. Doesn't block the execution flow and allows the program to continue. Ideal for use with I/O operations, network requests, fetching data. Handled with: Callbacks, Promises, Async/Await
